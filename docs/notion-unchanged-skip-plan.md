# Notion 동일 기록 작업 제외

## 목표와 범위

- 같은 recordId와 같은 백업 속성을 가진 Notion 행은 저장 작업 목록에서 제외한다. 금액·날짜·메모·카테고리 등 실제 변경은 계속 갱신한다.
- 브라우저 캐시를 믿고 건너뛰지 않고, 매 실행 시 실제 Notion 속성을 페이지 단위로 대조한다. 기존 행·로컬 거래는 삭제하지 않는다.
- 동일한 내용이라도 ID가 다른 거래를 임의로 합치지 않는다. 동일 금액·날짜의 정상 반복 결제를 보호한다.

## 구현과 검증

1. Worker 사전 대조 요청을 추가한다. 한 요청에 Notion 한 페이지만 조회하며 기존 속성 비교를 재사용한다.
2. 공통 클라이언트가 동일 ID 목록을 모으고 남은 ID만 저장 대상으로 보낸다. 카테고리 이름 매핑을 위해 원래 카테고리 목록은 보존한다.
3. 진행률에 사전 확인 단계·동일 기록 제외 건수를 표시한다. 다크 글래스·Pretendard·포커스·모바일 가독성을 유지한다.
4. 모두 동일/일부 변경/카테고리 이름 변경/페이지네이션/사전 확인 실패를 테스트하고 빌드·Worker 타입 검사·실제 운영 재실행과 화면 캡처로 검증한다.
