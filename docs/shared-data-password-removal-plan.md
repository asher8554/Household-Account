# 공유 데이터 암호 제거와 Notion 반영 확인

## 목표와 범위

- 공유 설정의 암호 입력 및 암호 필수 조건을 제거하고 이후 공유 커밋은 기존 JSON 백업 형식으로 기록한다.
- 토큰 인증, 원격 파일 병합, 충돌 재시도 및 급격한 데이터 변화 확인은 유지한다.
- 현재 운영 공유 파일은 암호화되어 있다. 기존 세션/과거 설정의 암호를 이용하는 읽기 호환 처리는 유지해 원격 데이터가 누락되지 않게 한다. 암호를 알 수 없는 원격 파일을 덮어쓰지 않는다.
- GitHub 공유 파일은 공개 저장소에 평문으로 커밋된다는 안내를 표시한다. 이번 작업에서는 실제 금융 데이터의 공개 커밋을 실행하지 않는다.
- Notion 기록 화면과 현재 기록 업데이트 결과에 카테고리 수를 포함한다. GitHub 실패 시 Notion 실행이 중단되는 기존 순서를 확인하고 실제 직접 Notion 기록의 완료·schema·행을 확인한다.
- 실사용 중 재현한 Notion 요청 제한은 Retry-After 대기 후 batch 재시도로 처리한다. 카테고리를 우선 저장하고 캘린더에는 categoryName을 표시한다.

## 검증

1. 암호 없이 공유 payload 생성, 기존 암호화 파일 읽기 및 토큰 필요 조건 회귀 테스트.
2. 기존 테스트와 빌드 실행. 범위 밖 기존 실패는 별도 보고한다.
3. 운영 사이트 배포 뒤 암호 입력 제거, 활성 버튼, 키보드 포커스, 다크 모드·글래스모피즘·Pretendard 렌더링을 확인한다.
4. 사용 중 브라우저에서 Notion 백업 진행·완료와 카테고리 이름 반영을 확인한다. 인증값·금융 데이터 파일은 저장소에 기록하지 않는다.
